Ethereus

Most models call tools outside themselves. Ethereus has the tool in its weights. A RISC-V computer is compiled into the layers of Qwen3.5-9B and runs Ethereum firmware: keccak, ABI encode and decode, CREATE and CREATE2 addresses, u256 arithmetic, small EVM programs, and a read-only store of Ethereum reference notes. Its answers are exact, replayed token by token against a reference machine. The fine-tune teaches the model to decide when to use it.
